### What I've learned the hard way

- An exit code says a process ended. It doesn't say the work happened. Check the artifact.
- A noticer without an actor isn't a system. Anything that can fail needs something that nags until it's fixed.
- Voice lives in one file. Every agent reads it; no agent rewrites it.
- Anything a stranger wrote never reaches a model that can touch your files.
